TERMINAL PORTFOLIO — SETUP NOTES

1. REPLACE YOUR PHOTO
   Swap out profile.jpg with your own photo (same filename, or update
   the `src="profile.jpg"` in index.html). Square images crop best.

2. EDIT YOUR INFO
   Open index.html and update:
   - Hero name, tagline, eyebrow text
   - About Me paragraphs and meta rows (location, focus, status)
   - Skills bars (edit width: XX% per skill)
   - Project cards (title, description, links)
   - Education/certificate timeline entries
   - Contact email, GitHub, LinkedIn links

3. CONTACT FORM
   The form currently only simulates sending (front-end demo).
   To make it functional, connect it to a service like Formspree,
   EmailJS, or your own backend endpoint in script.js.

4. RUN IT
   Just open index.html in any browser — no build step needed.
   For deployment: upload all 4 files (index.html, style.css,
   script.js, profile.jpg) to any static host (GitHub Pages,
   Netlify, Vercel, etc).
